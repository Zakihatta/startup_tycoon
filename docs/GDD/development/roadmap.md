# Development Roadmap

Roadmap baseline M0–M10; scope dapat direvisi dengan persetujuan.

| Milestone | Goal | Deliverables |
|---|---|---|
| M0 | Preproduction | Concept, GDD, technical blueprint, repo, coding rules |
| M1 | World + Player | 3D scene, camera, first-person movement, input |
| M2 | Interaction | Targeting, prompt, interact actions |
| M3 | Company + Finance + Time | Company state, cash, expenses, time |
| M4 | Product | One product, development progress, launch |
| M5 | Employee | Developer role, productivity, employee data |
| M6 | Market | Demand, simplified sales, revenue |
| M7 | Management UI | Dashboard, finance, product, employee UI |
| M8 | Office | Furniture, modularity, expansion foundation |
| M9 | Persistence | Save/load and validation |
| M10 | Prototype polish | Testing, usability, visual/audio polish |

## Principle
Setiap milestone menghasilkan state yang runnable dan reviewable. Pecah menjadi task kecil bila diperlukan.
