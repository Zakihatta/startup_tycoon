# Definition of Done

## Milestone checklist
- [ ] Milestone scope terpenuhi.
- [ ] `cargo check` berhasil.
- [ ] Runtime diuji.
- [ ] Fitur diuji manual.
- [ ] Unit/integration tests ditambahkan bila relevan.
- [ ] Regression yang diketahui ditangani.
- [ ] Dokumentasi diperbarui.
- [ ] Git checkpoint/commit dibuat.
- [ ] Known issues dicatat.
- [ ] Milestone dapat didemonstrasikan/review.

## Task completion
Task kecil tidak harus memenuhi semua checklist milestone, tetapi harus compile dan diuji sesuai risikonya.

## Quality principles
Code understandable, modular, no unrelated changes, assumptions/limitations documented, avoid duplicate sources of truth.
