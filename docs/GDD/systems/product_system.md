# Product System

## Purpose
Menciptakan, mengembangkan, meluncurkan, dan mengoperasikan produk software.

## Product lifecycle
**Idea → Planning → Development → Testing → Launch → Operation → Growth / Decline**

## MVP
- Satu software product.
- Product name.
- Product concept/category placeholder.
- Development progress.
- Quality/capability sederhana.
- Development cost/time.
- Testing milestone (simplified).
- Launch.
- Sales/revenue dari model market sederhana.

## Development factors
- Assigned worker(s).
- Worker skill.
- Productivity.
- Time.
- Task/product scope (scope MVP dibatasi).

## Future
Multiple products, feature selection/dependencies, technical debt, bugs/QA, updates, versions, portfolio, software categories.

## Constraints
Mulai dengan model development sederhana. Hindari feature tree kompleks sebelum core loop terbukti menyenangkan.
