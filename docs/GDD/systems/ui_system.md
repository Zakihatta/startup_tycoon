# UI System

## Purpose
Management interface dan informasi untuk keputusan bisnis.

## Planned screens
HUD, company dashboard, finance/report, product development, employee overview, hiring, market, office/build mode (future).

## MVP UI
- Cash/time HUD.
- Company overview.
- Product progress.
- Employee overview.
- Basic sales/finance report.
- Interaction prompts.

## Principles
- Minimalist, modern, legible.
- Hierarki informasi jelas.
- UI dibangun dengan Bevy UI, bukan image panel statis.
- Icons, portraits, logos, charts dan illustrations dapat menggunakan assets.

## Future
Navigation, detailed reports, notifications, charts, accessibility/scaling.
