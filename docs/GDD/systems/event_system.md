# Event System

## Purpose
Dinamika, tantangan dan peluang melalui kejadian terjadwal atau berbasis kondisi.

## Event ideas
Market trend changes, product traction, competitor announcement, unexpected expense, employee resignation (future), partnership opportunity, product issue/bug (future).

## MVP
Dapat ditunda atau dibatasi pada event sederhana setelah product-sales loop berjalan.

## Event design
- Trigger jelas (random, time, threshold, condition).
- Konteks yang dapat dipahami.
- Impact dijelaskan.
- Player diberi kesempatan merespons jika sesuai design.

## Future
Catalog, weighted selection, cooldown, event chains, choice-based events, persistence.
