# Employee System

## Purpose
Mengelola pekerja, hiring, skill, task assignment, kondisi, dan kontribusi.

## Proposed attributes
- ID
- Name
- Role
- Skill
- Salary
- Happiness
- Energy
- Productivity
- Experience
- State/task
- Traits/personality (future)

## MVP role
**Developer**

## MVP
- Satu employee (recruitment atau disediakan untuk prototype).
- Salary/expense.
- Skill sederhana.
- Productivity contribution pada product development.
- State sederhana (available / working / resting).
- Employee overview UI.

## Future roles
Designer, Marketing, Manager, QA, other specialist roles.

## Future mechanics
Hiring candidates, interviews, contracts, promotions, training, burnout, resignation, synergy, work schedule and task assignment.

## NPC presentation
NPC visual merepresentasikan employee data. Simulasi productivity tidak harus bergantung pada complex NPC AI.
